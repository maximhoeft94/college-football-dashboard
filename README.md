# College Football Dashboard

A single-page analytics dashboard covering the ACC, SEC, Big Ten, Big 12, Mountain West, and Pac-12 — standings, player leaderboards, head-to-head comparisons, and a play-by-play Expected Points (EPA) model. All 85 teams' schedules, box scores, and player stats are pulled from [CollegeFootballData.com](https://collegefootballdata.com) and baked directly into the page, so there's no backend and no API key needed to view it.

**▶ Live demo: [maximhoeft94.github.io/college-football-dashboard](https://maximhoeft94.github.io/college-football-dashboard/)**

## What it does

**Team Dashboard**

- Conference tabs (All Conferences, ACC, SEC, Big Ten, Big 12, Mountain West, Pac-12) that filter every section on the page
- Full standings sorted by record, points for/against, and point differential, with each team's previous and upcoming opponent
- A pick'em-style "Upcoming Week" schedule grouped by day, for whichever conference tab is active
- Season-long and per-game leaderboards for offense and defense: total yards, passing, rushing, points, and their "allowed" counterparts
- Passing, rushing, and receiving leaderboards, each split into overall and conference-only stats
- Team vs. team and player vs. player radar comparisons, a full box-score comparison, and a multi-week trend chart

**Head-to-Head**

- Side-by-side team radar charts across points, yards, sacks, and takeaways
- Player vs. player radar by position (QB, RB, WR, TE)
- Full per-game-average box score comparison between any two teams

[![Head-to-Head](https://github.com/maximhoeft94/college-football-dashboard/raw/main/screenshots/head-to-head.png)](https://github.com/maximhoeft94/college-football-dashboard/blob/main/screenshots/head-to-head.png)

**Expected Points Model**

- Built from every play of the season with a computed EPA (expected points added) value
- Offensive/defensive EPA per play, success rate, and explosive-play rate for any team
- EPA broken out by down, a cumulative EPA chart across the season, red zone efficiency, and a leaderboard of the season's most explosive plays
- The main Standings table can also be sorted by net EPA instead of record

## How it works

```
CollegeFootballData.com API ──(Python ETL)──▶ embedded JSON ──▶ single-page dashboard (vanilla JS + inline SVG)
```

- **Data source:** the [CollegeFootballData](https://collegefootballdata.com) API — schedules, team and player box scores, and play-by-play, for all 6 tracked conferences plus every out-of-conference opponent they play.
- **One file, no backend:** `index.html` is entirely self-contained. All season data is embedded as JSON at build time; every chart, table, and radar is rendered client-side with plain JavaScript and inline SVG — no charting library, no server, no API key required to view it.
- **Expected Points Model:** every play with a computed EPA value (~30k+ per refresh) is embedded per team, so the EPA charts and the sortable EPA column in Standings are computed live in the browser from the raw plays.

**Stack:** Python (ETL) · vanilla JavaScript · inline SVG · HTML/CSS · CollegeFootballData API · GitHub Pages

## Updating the data

There's no build step to run — the page is regenerated by re-pulling the season's data (standings, box scores, player stats, and play-by-play) from the CollegeFootballData API and re-embedding it into `index.html`, then pushing.
